# NOVA Audio storefront

Next.js app for the NOVA Audio product experience. Setup, environment variables, and deploy notes are in the [repository README](../README.md).

```bash
npm install
npm run dev
```

Production:

```bash
npm run build
npm run start
```

The dev server listens on [http://localhost:3000](http://localhost:3000). Copy `.env.example` to `.env.local` before pointing the app at a non-local API.
