# NOVA Audio storefront

Next.js app for the NOVA Audio product experience. Setup, environment variables, and deploy notes are in the [repository README](../README.md).

```bash
npm install
npm run dev
```

Production:

```bash
npm run build
npm run start
```

Copy `.env.example` to `.env.local` and set `NEXT_PUBLIC_API_URL`. The deployed storefront is [https://nova-audio-163.netlify.app](https://nova-audio-163.netlify.app).
